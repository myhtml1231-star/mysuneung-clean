# Full-service admin release · 2026-09-29

운영 주소: https://mysuneung.com/admin

## 구현 범위
- 운영 개요: 가입 회원, 오늘 로그인 이벤트, 7일 로그인 회원, 현재 로그인 기기, 오늘 방문자, 최근 7일 CBT, 14일 활동 차트
- 회원 관리: 검색/상태 필터, 가입일, 최근 로그인, 누적 로그인, CBT, 활성 기기, 상세 로그인 이력, 이용정지/재개, 세션 강제 종료
- 학습 분석: 유형별 첫 응답 정확도와 회원별 우선 취약 신호
- 문의 관리: 기존 Firestore inquiries를 그대로 읽고 답변/삭제. 기존 비공개 문의의 password 필드는 관리자 API 응답에서 제거
- 오류 신고: 기존 mysuneung-admin D1의 reports를 검색/처리 상태/관리자 메모/삭제
- 수험 채팅: 기존 Firestore chatMessages 최근 메시지 검색/삭제
- 운영 로그: 회원 상태, 세션, 문의, 채팅, 오류 신고 변경 감사 로그

## 로그인 추적
배포 이후 로그인 성공마다 account_login_events에 이벤트를 저장합니다. 배포 전 과거 로그인 횟수는 복원할 수 없으므로, 전환 당시 활성 세션만 session_backfill로 1건 이관했습니다. 관리자 화면은 추적 시작 시점을 명시합니다.

## 관리자 권한
D1 admin_accounts RBAC을 사용합니다. 전환 당시 운영 계정이 1개였으므로 해당 기존 계정을 최초 owner로 이관했습니다. 일반 회원은 관리자 API에서 403으로 차단됩니다.

## 중요 보안 후속
기존 질문 게시판은 Firestore 문서를 브라우저에서 직접 읽는 레거시 구조라 inquiries 문서의 password 필드도 클라이언트가 읽을 수 있는 상태임을 확인했습니다. 이번 관리자 API는 해당 필드를 절대 반환하지 않지만, 공개 질문 게시판 자체의 비공개 질문 인증 구조는 별도 서버 API로 이관하는 것이 필요합니다. 기존 비밀번호 값은 본 검증 기록에 출력하거나 저장하지 않았습니다.
