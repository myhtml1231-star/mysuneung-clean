# 직업탐구·제2외국어 기출 자료 확대

기존 홈페이지의 83개 회차 선택 페이지를 EBSi 공식 기출 목록과 대조했다. 이미 추가한 2026년 10월 두 회차를 유지하며, 추가로 25개 회차에 395개 과목(직업탐구 174, 제2외국어·한문 221)을 연결한다. 과거 교육과정의 직업탐구 과목명과 당시 시행 과목 수를 보존한다. 공식 자료가 없는 영역에는 메뉴를 만들지 않는다.

문제·해설 PDF 790개는 공식 원본을 바이트 단위로 보존했다. 정답 PDF 395개는 EBSi 정답 이미지 전체를 그대로 넣었으며, 삽입된 이미지가 원본과 픽셀 단위로 일치하는 것을 전수 검사했다. PDF 1,185개의 출처·해시·크기는 별도 명세에 있다. 기존 선택 페이지의 모든 링크와 각 페이지의 CSS 블록을 유지한다.

EBSi의 내부 시험 레코드 식별자와 실제 게시 파일 날짜가 다른 자료가 있으므로, 화면의 회차와 원문 PDF 제목 및 게시 URL을 기준으로 식별한다. `source_exam_date`는 공식 문제 파일의 경로에서 확인한 날짜다. 일부 제2외국어 PDF의 머리말은 글자가 윤곽선으로 그려져 있어 텍스트 추출 결과에 나타나지 않는다. 이는 원문 훼손이나 누락을 뜻하지 않는다.

파일은 기존 공개 R2 버킷의 `archive/voc-lang-20261023/`에 보관하고, HTML은 기존 정적 사이트 저장소로 배포한다. 현재 10월 자료, CBT 엔진, 로그인·계정·저장 기능 및 대학 사이트는 수정하지 않는다.
