# 수학 CBT 운영 반영 · 2026-09-29

진입: 기존 `/mixed-cbt` 첫 화면의 **수학** 탭. 직접 경로 `/mixed-cbt?subject=math`.

## 수록 범위

공식 EBSi 기출 목록에서 문제·해설 PDF 216개를 확보했습니다. 44회차, 108종 시험지의 3,240개 문항 참조를 검증하고, 공통문항 중복 880개를 제거한 2,360문항을 제공합니다.

| 학년도 | 반영 범위 |
|---|---|
| 2014–2016 | 평가원 6·9월 및 수능, A/B형 |
| 2017–2021 | 평가원 6·9월 및 수능, 가/나형 |
| 2022–2026 | 평가원 6·9월 및 수능, 확률과 통계·미적분·기하 |
| 2027 수능 대비 | 공개된 2026년 3·5·6·7·9월, 확률과 통계·미적분·기하 |

아직 시행되지 않은 2027학년도 수능은 제외했습니다. 과거 모든 교육청 회차를 포함했다고 주장하지 않습니다. 원문 URL, 시행일, 파일 SHA-256, 문항·정답·배점 검증 정보는 별도로 기록했습니다.

## 화면과 풀이

국어 CBT의 기존 화면·필기 엔진·채점 리포트 구성을 사용했습니다. 국어/수학 선택 탭만 추가했으며, 국어는 기존 경로의 기본 과목입니다. 수학은 왼쪽 풀이 노트, 오른쪽 원문, 번호형 답안표를 사용합니다.

실전 모드는 30문항, 100점, 100분이며 객관식 21문항과 단답형 9문항입니다. 현행 시험은 공통 22문항과 선택 8문항으로 원래 문항 위치·배점을 유지합니다. 이전 A/B·가/나형 실전은 한 회차 전체 시험지를 제공합니다. 맞춤 모드는 1–30문항입니다. 서로 다른 체제를 한 실전 시험에 섞지 않습니다.

수식·분수·도형은 OCR로 재작성하지 않고 문제 PDF를 무손실 이미지로 표시합니다. 공통 자료가 있는 16개 묶음은 자료를 함께 제공합니다. 단답형 0은 정상 답안으로 저장하며 미응답과 구분합니다. 점수와 정답은 서버의 기준 데이터로 다시 계산합니다.

## 분석·복습

공식 해설의 출제의도를 기반으로 유형을 분류하고, 공부 순서와 사용자가 선택한 오답 이유에 따른 팁을 제공합니다. 넓이·최댓값이라는 말만으로 미적분을 단정하거나, ‘여러 가지 수열’을 ‘지수’로 잘못 읽는 규칙은 배제했습니다.

분류가 보류된 89문항은 점수에 포함하지만 유형 진단에서는 제외합니다. 기존의 첫 응답·최소 근거·미응답 구분·지연 재확인 규칙을 재사용합니다. 보완 문제는 같은 교육과정의 다른 회차에서 고르며, 최근에 본 문항과 같은 공통 자료를 새 근거로 세지 않습니다.

EBS는 해당 문항의 공식 정답·해설과 위치를 연결했습니다. 검증되지 않은 EBS 교재 연계를 표시하거나 자동 완주 처리하지 않습니다.

## 기록·보안

국어/수학 풀이 기록과 임시 저장을 별도 키로 관리합니다. 계정 저장, 수학 이어풀기, 문항 필기, 원점수, 단답형 0을 지원합니다. 다른 계정의 기록은 접근할 수 없습니다. 정답 기준 JSON은 서버 번들에만 포함하며 공개 정적 파일로 배포하지 않습니다.

부수적으로 정상 로그인 두 건이 같은 밀리초에 발생하면 저장을 거절하던 기존 중복 인덱스 문제를 수정했습니다. 기존 로그인 이벤트는 삭제하지 않았습니다.
