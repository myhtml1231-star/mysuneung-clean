# 직업탐구·제2외국어/한문 CBT와 통계 보완

대상은 27회차의 416개 과목 시험지(직탐 181, 제2외국어/한문 235), 총 10,605문항이다. 고3 2020~2026학년도 6월·9월·수능, 2027학년도 6월·9월·10월과 고2 2024~2026년 10월에 실제 시행된 과목만 수록한다. 시행하지 않은 과목·회차는 만들지 않는다.

## 운영 자료

- R2 바인딩 CBT의 실제 버킷은 `mysuneung-cbt`이다. 자료 경로는 `vocational/20261023-v1/`이다.
- `banks/`의 서버 채점 자료와 `packs/`의 원문 패킷을 공개 CBT 경로에서 차단한다. 문제 이미지는 검증된 패킷의 byte range로 제공한다.
- 원문을 다시 쓰지 않고 공식 PDF의 문제·선지·공통 자료를 그대로 표시한다. 고2 2026년 10월 직탐은 25문항·40분, 제2외국어는 20문항·30분이다. 고3 직탐은 20문항·30분, 제2외국어는 30문항·40분이다.
- 등급컷 표 416개와 EBSi 오답률 TOP15 6,240개 행을 연결한다. 전체 시험 난이도 설문이 공개되지 않은 회차에는 수치를 만들지 않는다. TOP15 평균을 과목 전체 난이도로 표시하지 않는다.
- 새 과목의 검토되지 않은 단원·유형 분류는 전체 기출 문항으로만 제공한다. 개인 취약 유형이나 전이 학습의 근거로 사용하지 않는다.

## 소스·검증

`runtime/`은 실제 배포한 번들 스냅샷이다. CBT Worker의 `index.js`는 `mysuneung-cbt-api.mjs` 내용이며, 계정 Worker는 기존 모듈을 보존하고 `admin_base.mjs`만 갱신한다. 기존 로그인·계정 소유권·CSRF 검사와 다른 과목 경로를 유지한다. 운영 바인딩을 변경하지 않는다.

`source/`는 서버 채점, 계정 검증 및 클라이언트와 검사 스크립트다. `evidence/`에 전체 416개 시험지, 10,605개 원문 이미지, 6,240개 정답·배점 대조, 계정 전환 및 오프라인 대기열 검사 결과를 보존한다. 로컬 브라우저 검증은 운영 검증과 구분한다.

기존 다운로드 페이지 416개, 회차 선택 27개, 등급컷 27개와 난이도·오답률 27개의 스타일 블록 및 기존 다운로드 링크를 보존했다. 새 기능은 기존 버튼·표·필터 형식으로 연결한다.

공식 출처 URL은 각 등급컷·오답률 페이지와 은행의 원문 메타데이터에 보존한다. 원문 파일과 패킷은 GitHub HTML 저장소에 중복 업로드하지 않는다.
